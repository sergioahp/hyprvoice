  Here is a minimal **Python microphone → WebSocket → streaming transcript      
  deltas** example for `gpt-realtime-whisper`.                                  
                                                                                
  OpenAI’s realtime transcription docs say this path is for live                
  speech-to-text, uses a session with `type: "transcription"`, and recommends   
  `gpt-realtime-whisper` for the lowest-latency streaming transcription path.   
  Audio is sent via `input_audio_buffer.append`, and you receive                
  `conversation.item.input_audio_transcription.delta` plus final `completed`    
  events. ([OpenAI Developers][1])                                              
                                                                                
  ```bash                                                                       
  pip install websocket-client sounddevice numpy                                
  export OPENAI_API_KEY="sk-..."                                                
  python realtime_whisper_mic.py                                                
  ```                                                                           
                                                                                
  ```python                                                                     
  # realtime_whisper_mic.py                                                     
  import os                                                                     
  import json                                                                   
  import base64                                                                 
  import queue                                                                  
  import signal                                                                 
  import sys                                                                    
                                                                                
  import numpy as np                                                            
  import sounddevice as sd                                                      
  import websocket                                                              
                                                                                
                                                                                
  OPENAI_API_KEY = os.environ["OPENAI_API_KEY"]                                 
                                                                                
  # OpenAI docs recommend 24 kHz mono PCM for audio/pcm input.                  
  SAMPLE_RATE = 24_000                                                          
  CHANNELS = 1                                                                  
  CHUNK_MS = 100                                                                
  FRAMES_PER_CHUNK = int(SAMPLE_RATE * CHUNK_MS / 1000)                         
                                                                                
  audio_q: queue.Queue[bytes] = queue.Queue()                                   
  running = True                                                                
                                                                                
                                                                                
  def audio_callback(indata, frames, time, status):                             
      if status:                                                                
          print(status, file=sys.stderr)                                        
                                                                                
      # sounddevice gives float32 by default in [-1.0, 1.0].                    
      pcm16 = np.clip(indata[:, 0], -1.0, 1.0)                                  
      pcm16 = (pcm16 * 32767).astype(np.int16)                                  
      audio_q.put(pcm16.tobytes())                                              
                                                                                
                                                                                
  def on_open(ws):                                                              
      print("Connected. Start speaking. Ctrl+C to stop.")                       
                                                                                
      # Configure this as a transcription-only realtime session.                
      ws.send(json.dumps({                                                      
          "type": "session.update",                                             
          "session": {                                                          
              "type": "transcription",                                          
              "audio": {                                                        
                  "input": {                                                    
                      "format": {                                               
                          "type": "audio/pcm",                                  
                          "rate": SAMPLE_RATE                                   
                      },                                                        
                      "transcription": {                                        
                          "model": "gpt-realtime-whisper",                      
                          "language": "en"                                      
                      },                                                        
                      "turn_detection": {                                       
                          "type": "server_vad",                                 
                          "threshold": 0.5,                                     
                          "prefix_padding_ms": 300,                             
                          "silence_duration_ms": 500                            
                      }                                                         
                  }                                                             
              }                                                                 
          }                                                                     
      }))                                                                       
                                                                                
      def stream_audio():                                                       
          with sd.InputStream(                                                  
              samplerate=SAMPLE_RATE,                                           
              channels=CHANNELS,                                                
              dtype="float32",                                                  
              blocksize=FRAMES_PER_CHUNK,                                       
              callback=audio_callback,                                          
          ):                                                                    
              while running:                                                    
                  chunk = audio_q.get()                                         
                  b64 = base64.b64encode(chunk).decode("ascii")                 
                                                                                
                  ws.send(json.dumps({                                          
                      "type": "input_audio_buffer.append",                      
                      "audio": b64                                              
                  }))                                                           
                                                                                
      import threading                                                          
      threading.Thread(target=stream_audio, daemon=True).start()                
                                                                                
                                                                                
  def on_message(ws, message):                                                  
      event = json.loads(message)                                               
                                                                                
      t = event.get("type")                                                     
                                                                                
      if t == "conversation.item.input_audio_transcription.delta":              
          print(event.get("delta", ""), end="", flush=True)                     
                                                                                
      elif t == "conversation.item.input_audio_transcription.completed":        
          print("\n\nFinal:", event.get("transcript", ""))                      
                                                                                
      elif t == "error":                                                        
          print("\nERROR:", json.dumps(event, indent=2), file=sys.stderr)       
                                                                                
                                                                                
  def on_error(ws, error):                                                      
      print("WebSocket error:", error, file=sys.stderr)                         
                                                                                
                                                                                
  def on_close(ws, close_status_code, close_msg):                               
      print("\nClosed:", close_status_code, close_msg)                          
                                                                                
                                                                                
  def handle_sigint(sig, frame):                                                
      global running                                                            
      running = False                                                           
      print("\nStopping...")                                                    
      sys.exit(0)                                                               
                                                                                
                                                                                
  signal.signal(signal.SIGINT, handle_sigint)                                   
                                                                                
  url = "wss://api.openai.com/v1/realtime?model=gpt-realtime-whisper"           
  headers = [                                                                   
      f"Authorization: Bearer {OPENAI_API_KEY}",                                
      "OpenAI-Safety-Identifier: dev-local-test-user",                          
  ]                                                                             
                                                                                
  ws = websocket.WebSocketApp(                                                  
      url,                                                                      
      header=headers,                                                           
      on_open=on_open,                                                          
      on_message=on_message,                                                    
      on_error=on_error,                                                        
      on_close=on_close,                                                        
  )                                                                             
                                                                                
  ws.run_forever()                                                              
  ```                                                                           
                                                                                
  A few common gotchas:                                                         
                                                                                
  The endpoint is a **Realtime WebSocket**, not `/v1/audio/transcriptions`. The 
   WebSocket guide shows server-side connections using                          
  `wss://api.openai.com/v1/realtime?...` with the `Authorization: Bearer ...`   
  header. ([OpenAI Developers][2])                                              
                                                                                
  For this model, use a **transcription session** and set:                      
                                                                                
  ```json                                                                       
  {                                                                             
    "session": {                                                                
      "type": "transcription",                                                  
      "audio": {                                                                
        "input": {                                                              
          "transcription": {                                                    
            "model": "gpt-realtime-whisper"                                     
          }                                                                     
        }                                                                       
      }                                                                         
    }                                                                           
  }                                                                             
  ```                                                                           
                                                                                
  Do not use the older assistant-style realtime session shape unless you        
  actually want a voice agent. OpenAI’s docs distinguish realtime transcription 
   from realtime assistant responses. ([OpenAI Developers][1])                  
                                                                                
  Audio format matters. The docs specify `audio/pcm` at **24 kHz mono PCM**     
  when sending that format, and chunks must be Base64 encoded in                
  `input_audio_buffer.append`. ([OpenAI Developers][1])                         
                                                                                
  With `server_vad`, you do **not** manually call `input_audio_buffer.commit`;  
  the server commits when it detects a turn boundary. If you set                
  `turn_detection: null`, then you must send `input_audio_buffer.commit`        
  yourself. ([OpenAI Developers][1])
